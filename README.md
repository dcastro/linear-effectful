# `linear-effectful`

This repository is (for now) a proof of concept for using [`effectful`'s
effect system](https://hackage.haskell.org/package/effectful) with
[linear `IO` from
`linear-base`](https://hackage-content.haskell.org/package/linear-base/docs/System-IO-Linear.html).

It defines a `LEff` monad (read: "linear effect"). You can embed `LEff`
programs in `Eff` programs using `runLEff`, and vice-versa using
`liftEff`.

It also defines a `WithResource` effect that can only be run in `LEff`,
isomorphic to [`linear-base`'s
`RIO`](https://hackage-content.haskell.org/package/linear-base/docs/System-IO-Resource-Linear.html),
with the following guarantees:

- Resources must always be released.
- Resources cannot be released twice.
- Resources cannot be used after being released.
- Resources cannot escape the scope where they were created.

A quick demo of a `FileSystem` effect built on top of `LEff` +
`WithResource` can be found in
[test/Example/Effectful/Linear/Demo.hs](test/Example/Effectful/Linear/Demo.hs)

This repo also contains a `LEff` "adapter" for
[`linear-locks`](https://hackage.haskell.org/package/linear-locks) in
[./examples/linear-locks-effectful/](./examples/linear-locks-effectful/).
When/if `linear-effectful` leaves the "proof of concept" stage,
`linear-locks-effectful` will be moved to its own repo.

``` haskell

app2 :: (Locks :> es, WithIO :> es) => Eff es String
app2 = do
  mutex <- Mutex.new @String 0 "hello"
  lockScope \key -> Linear.do
    (mg, key) <- Mutex.acquire key mutex
    (Ur str, mg) <- Mutex.read mg
    Mutex.release mg
    dropKeyAndReturn key str
```
